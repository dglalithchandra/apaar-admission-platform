# Applications

Planned web surfaces share one design system but have different information architecture:

- `institution-portal` — intake reconciliation, file upload, correction queues and submission receipts.
- `regulator-console` — national monitoring, anomaly triage, policy administration and audit review.
- `verification-portal` — minimal, consent-aware verification for authorised external parties.
- `student-view` — read-only admission status, identity-link state, consent history and dispute entry.
- `design-system` — tokens, accessible primitives, content patterns and Storybook states.

The first vertical slice should be institution upload through validation and receipt generation. Do not start with a decorative dashboard.
