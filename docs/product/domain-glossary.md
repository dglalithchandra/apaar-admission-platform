# Domain glossary

This glossary uses plain language first. Formal definitions must later be reconciled with current AICTE policy.

| Term                             | Plain meaning                                                                          | Product treatment                                                                                                                                |
| -------------------------------- | -------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------ |
| APAAR ID                         | A national academic identity used to connect a learner to academic records.            | An external identifier verified through an adapter. It is not used as the database primary key and must never be guessed or silently corrected.  |
| AICTE institution ID             | The regulator's identifier for an approved institution.                                | Linked to effective-dated institution status and campuses.                                                                                       |
| Academic year                    | The admission cycle to which capacity and admissions belong.                           | Explicit on every approval and admission; never inferred only from upload date.                                                                  |
| Programme                        | A regulated course at a campus, level and mode.                                        | Capacity is attached to a specific programme occurrence, not merely an institution.                                                              |
| Approved intake                  | The maximum ordinary intake authorised for a programme and academic year.              | Stored as an immutable approval snapshot with source and effective dates.                                                                        |
| Actual enrolment                 | Students whose admission records reached an accepted lifecycle state.                  | Counted from authoritative records, never from a manually entered total.                                                                         |
| Supernumerary seat               | An authorised seat outside the ordinary approved intake for a defined policy category. | Kept in a separate capacity bucket; it must not disguise excess ordinary admissions.                                                             |
| NRI category                     | Admission under a Non-Resident Indian category where policy permits it.                | Represented as a category and evidence requirement, not assumed from nationality.                                                                |
| OCI status                       | Overseas Citizen of India status.                                                      | A distinct status that may affect identity/evidence rules; it is not the same as foreign national.                                               |
| Foreign National status          | A student who is not an Indian national under the applicable rule.                     | May require an approved alternative to APAAR and additional evidence.                                                                            |
| Institutional student ID         | The institution's own identifier for the learner.                                      | Unique within an explicit institution scope and displayed beside APAAR where policy permits.                                                     |
| Admission receipt                | Immediate proof that a batch or record was received.                                   | Includes hash, template version, submitter, row counts and timestamp; it does not mean every row is accepted.                                    |
| Admission Registration Reference | Stable reference for an accepted admission record.                                     | Issued only after required validations; remains traceable through later corrections.                                                             |
| Exam roll/seat number            | Identifier assigned for an examination event.                                          | Belongs to the examination system and may change by exam. It is not the student's national academic identity.                                    |
| Hall ticket/admit card           | Permission and logistical details for sitting an examination.                          | External evidence only; not proof of programme capacity compliance.                                                                              |
| Certificate/degree/diploma       | Formal award issued by an authorised degree-awarding body.                             | The platform can verify linked admission facts and later integrate with signed credentials; it must not pretend AICTE issued an academic award.  |
| Transcript                       | Detailed record of courses, credits and results.                                       | Usually owned by the institution/university or NAD/DigiLocker ecosystem, not by admission registration.                                          |
| Duplicate record                 | The same admission submitted more than once.                                           | Prevented with idempotency keys and deterministic record identity.                                                                               |
| Overlapping enrolment            | The same person appears in admissions whose dates or modes may conflict.               | Creates a reviewable case because some overlaps can be legitimate.                                                                               |
| Correction                       | A controlled change to an existing record with reason and evidence.                    | Preserves previous values and approval history.                                                                                                  |
| Cancellation                     | Admission ceases to be active from a recorded effective date.                          | Releases capacity only according to the governing policy; history is retained.                                                                   |
| Consent                          | A specific, recorded permission where consent is the appropriate legal basis.          | Purpose, scope, actor, timestamp, notice version and withdrawal are recorded. Consent is not used as a blanket substitute for lawful governance. |
