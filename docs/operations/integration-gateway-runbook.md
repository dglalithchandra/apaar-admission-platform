# Integration gateway operations runbook

## Safe startup

Production startup must reject synthetic authentication and APAAR simulation. Inject credentials through the deployment secret manager, never environment examples committed to Git. `/health` proves the process is alive; `/ready` reports only dependency classes and returns 503 when a required dependency is degraded.

## Dependency failure

APAAR timeout, 429 or provider failure remains retryable/unavailable and must never be converted to invalid identity. Notification failure never rolls back a committed regulatory transaction. Dead-lettered notifications require an authorized operational review using only notification, request and correlation references.

## Verification receipts

Confirm requester organization, purpose, claim allow-list and consent/legal basis before issuance. Receipts expire after fifteen minutes. Revoke by appending a revocation record; never edit the receipt. The synthetic signing algorithm is never valid outside local acceptance.
